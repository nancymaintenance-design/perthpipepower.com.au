Keeping access information with the repair request

Property access can influence how a maintenance enquiry is coordinated. Include the on-site contact, notice requirements, building-entry information, parking notes and any relevant strata or building-management detail with the issue description.

Share only what is needed

Avoid including unnecessary sensitive information. Access codes and occupant information should be shared through an appropriate channel and only for the service request.

When the scope or access arrangements change, update the same request record so people are working from the current information.
