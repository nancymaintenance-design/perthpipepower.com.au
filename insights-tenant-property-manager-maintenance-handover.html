Managed properties

A clear maintenance handover between tenants and property managers

Maintenance requests can lose important detail when they pass from an occupant to a property manager and then to a service contact. A short structured handover keeps observable facts together.

Use this checklist

  1. Property address and unit number
  2. Occupant’s description in their own words
  3. Affected room, fixture or circuit
  4. When it began and whether it is worsening
  5. Safe action already taken
  6. Photos taken safely
  7. Availability, access, pets, parking or induction details
  8. Work-order reference and approval pathway
  9. Shared service or strata information

Keep updates in the same email thread or work-order record where practical. If a slow drip becomes an active flow, state the new condition and time clearly.
