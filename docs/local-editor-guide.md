# 本地中文草稿编辑首版

本轮为首版检查点，不是完整双语发布版本。

## 打开与编辑

后台：http://127.0.0.1:4200/__editor/

选择页面，在预览里点击正文或标题，再在右侧输入中文并点击“保存中文草稿”。也可通过“文字位置”列表选择 SEO 标题、SEO 描述。保存成功后预览更新。清空输入并保存，会移除此字段的中文覆盖，恢复显示英文原文。

初次启动提供首页正文中文初稿，其余页面可逐项填写。电话、邮箱、价格、地址等业务事实锁定；FAQ、共享导航／页尾与图片暂不开放编辑。未翻译区域保留英文并明确标注，不宣称全站翻译完成。

中文草稿独立保存在 source/.local-editor/drafts/，刷新和服务重启后仍保留。保存不会修改英文、不会发送邮件、不会上线。最近20次修订留档；可视化历史恢复仍待后续实现。

多窗口出现修订冲突时，不会覆盖新草稿；先复制保留当前输入，再重新载入核对。

## 再次启动

在 E:/Ellis-Services/Perth Pipe Power/source 中运行：

```powershell
npm run editor:dev
```

服务仅监听127.0.0.1。4200已占用时自动使用后续空闲端口，以终端打印的实际地址为准。前台终端方式运行时，保持终端打开；Ctrl+C停止服务。

中文预览：/zh/；英文参照：/。预览关闭真实咨询提交和页面跳转／联系操作，保留地图、链接内容和完整页尾用于查看。源站运行逻辑未改变。
