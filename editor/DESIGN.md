# Ellis 本地内容编辑器

规范视觉来源为父目录 [DESIGN.md](../DESIGN.md) 和 `../field-design.css`；本文件仅记录本地后台对既有规范的应用，不定义第二套主题。

后台为单人中文内容校对工具。沿用海军蓝页头、蓝色主要操作、浅蓝工作区和白色编辑面板；现有 `--field-*` 是唯一品牌 Token 来源（Model B）。显示字体沿用 Arial／微软雅黑。签名是原版网站实时预览与中文字段编辑并排，不采用营销卡片或重做网站英雄区。

桌面预览加自然高度编辑栏；980px以下编辑栏在前、预览在后。iframe拥有网站滚动，正文表单不锁定高度。手机预览可缩为390px且不超过实际可用宽度。保存按钮保持宽度；错误与状态有稳定位置。全局滚动条由 ui/editor.css 的 editor-app 基线统一控制，强制颜色模式使用系统样式。

输入／选择器使用原生 HTML 控件，接受平台弹出菜单外观。共享交互、中文状态、草稿修订保护和对话框遵循 [UX-CONTRACT.md](UX-CONTRACT.md)。确认只作用于本地候选，绝不伪装成发布。所有后台操作在客户端加载前禁用；加载或网络失败不丢弃输入。
